# Wi-Fi 功能所需图标

以下是 Wi-Fi 设置页面需要的图标文件：

## 信号强度图标

- `/static/images/wifi-strong.png` - 强信号图标（3格满）
- `/static/images/wifi-medium.png` - 中等信号图标（2格）
- `/static/images/wifi-weak.png` - 弱信号图标（1格）

## 功能图标

- `/static/images/wifi-off.png` - Wi-Fi 关闭状态图标
- `/static/images/lock.png` - 加密网络锁图标
- `/static/images/eye-open.png` - 显示密码图标
- `/static/images/eye-close.png` - 隐藏密码图标

## 图标规格建议

- 信号强度图标：40x40rpx
- 功能图标：根据实际使用场景调整
- 格式：PNG，支持透明背景
- 颜色：与应用主题色保持一致
