## API

#### `Button` 按钮

| 属性           | 类型      | 说明                                           |
| -------------- | --------- | ---------------------------------------------- |
| `data`         | `[{}]`    | swiper 数据，必须有 id,img(地址)两个值（必填） |
| `delay`        | `number`  | 自动轮播延迟时间                               |
| `pictureWidth` | `number`  | 图片宽度                                       |
| `autoPlay`     | `boolean` | 是否自动轮播默认 false                         |
| `height`       | `number`  | 图片高度                                       |
